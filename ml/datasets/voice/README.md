# KalaSetu Voice & Language Dataset

This directory is reserved for multilingual voice and speech datasets.

The current Model 11 implementation is a prototype baseline and does not
claim research-valid speech recognition accuracy.

Future research dataset requirements:

- Kannada artisan speech
- Hindi artisan speech
- English artisan speech
- Marathi artisan speech
- Tamil artisan speech
- Telugu artisan speech
- Product-related speech
- Pricing-related speech
- Market-related speech
- Craft descriptions
- Noisy real-world recordings
- Multiple speakers
- Different accents
- Different recording environments

The research version should compare multiple speech recognition approaches,
including a lightweight baseline and transformer-based speech recognition.
